# Órbita — Explorador del sistema solar

Simulador interactivo en 3D para explorar los ocho planetas del sistema solar. Selecciona un planeta para consultar sus datos, arrastra la escena para cambiar el punto de vista y utiliza los controles para ajustar el zoom, la velocidad y la visualización de las órbitas.

## Requisitos

- Node.js 20.19 o posterior
- npm

## Desarrollo

```bash
npm install
npm start
```

Abre `http://localhost:4200` en un navegador con WebGL habilitado.

## Flujo de ramas

- `develop`: integración de funcionalidades.
- `release`: validación y preparación de versiones.
- `master`: versiones estables.

## Verificación

```bash
npm test
npm run build
```
